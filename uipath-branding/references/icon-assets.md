## Filename Metadata

- `SVG`: vector icon format.
- `white`: use on dark, colored, or image backgrounds with adequate contrast.
- `dark grey` / `dark gray`: use on white or light backgrounds.
- `96 pixels`: intended source size; scale SVGs proportionally as needed.
- Words before `_SVG ... 96 pixels.svg` are semantic names and search keywords.

## Selection Rules

- Search `icon-index.md` or `icon-index.json` by concept first, then select the color variant for the background.
- Prefer white icons on Deep Blue, black, Robotic Orange, Agentic Teal, photography, or other dark/saturated backgrounds.
- Prefer dark-grey icons on Bright White, near-white, light grey, or pale tint backgrounds.
- Keep the SVG proportional. Do not stretch, crop, or distort icons.
- Treat icons as supporting communication elements; do not use them as replacement logos or decorative filler.
- If a matching white/dark-grey pair does not exist, choose the closest concept from the catalog rather than recoloring unless the output system explicitly supports approved brand icon colorways.
- Use semantic UiPath color associations when composing icon modules: Agentic Teal for agents, Robotic Orange for robots, and Bright White or light neutrals for people.
